🚀 Junior Developer Learning Path

The 300 questions cover ~90% of the HTML & CSS topics you'll typically need for day-to-day work.

🚀 Next Up: Advanced CSS & HTML (Important to know)

  • Responsive Media: <picture>, srcset, and responsive images.
  • Web Components: <template>, <slot>, and Web Components basics.
  • Global Attributes: contenteditable, spellcheck, translate, draggable, data-* attributes.
  • Links & File Inputs: download, accept, and capture in file inputs.
  • Mobile Keyboard UX: inputmode, enterkeyhint.
  • Advanced Forms: form attribute (linking inputs outside <form>), formaction, formmethod, formenctype, novalidate, formnovalidate.
  • Container Queries: @container (Essential for component-based frameworks like Angular).
  • Advanced Pseudo-elements: ::marker, ::selection, ::placeholder, ::file-selector-button.
  • Custom Form Controls: Styling checkboxes/radios with appearance: none, :valid, :invalid, :checked, :placeholder-shown.
  • CSS Functions (Deep Dive): env(), attr(), fluid typography using clamp().
  • CSS Transforms: 3D Transforms (perspective, transform-style), transform-origin.
  • Animation Properties: animation-fill-mode, direction, iteration-count, timing-function, play-state, cubic-bezier.
  • Multi-column Layout: columns, column-gap, column-rule.
  • Typography: @font-face, font-display, text-wrap: balance.
  • Native HTML5: Native dialog element, Drag & Drop API, Advanced Tables (scope, colspan).

🅰️ Angular-Specific CSS

  • View Encapsulation: Emulated, None, ShadowDom.
  • Component Styling: :host and :host-context for styling the component element itself.
  • Deep Selectors: ::ng-deep (when to use and when to avoid).
  • Component Libraries: Overriding PrimeNG, Angular Material, and Tailwind styles effectively.
  • Overcoming Conflicts: Specificity battles, Global Styles, Library Themes, and Cascade Layers.

🟠 Low Priority (For Now)

  • CSS Houdini, @property, Paint API, Typed OM.
  • Anchor Positioning.
  • Advanced Scroll-driven Animations.
  • View Transitions API.
  • Complex masking & Advanced filters/compositing.
  • Subgrid (mostly future-proofing).

Q131 — What is the difference between justify-content, align-items, and align-content in Flexbox? Medium

✅ Ideal answer
  • justify-content controls distribution along the main axis.
  • align-items controls alignment along the cross axis within a single flex line.
  • align-content controls the distribution of multiple flex lines along the cross axis.
🔁 Follow-up: When does align-content have an effect? It matters when the flex container has multiple lines, usually because flex-wrap: wrap is enabled and there is extra space along the cross axis.

💻 Code

style.css — Visual Studio Code
style.css
.container {
  display: flex;
  flex-wrap: wrap;
  justify-content: space-between;
  align-items: center;
  align-content: space-around;
}

Q132 — What is the difference between align-items and align-self? Medium

✅ Ideal answer align-items is set on the flex container and defines the default cross-axis alignment for its flex items.

align-self is set on an individual flex item and allows that item to override the container's align-items value.
🔁 Follow-up: Can align-self override justify-content? No. align-self controls the item's alignment on the cross axis. justify-content controls distribution along the main axis.

💻 Code

style.css — Visual Studio Code
style.css
.container { display: flex; align-items: center; }
.special { align-self: flex-start; }

Q133 — What is the difference between flex-grow, flex-shrink, and flex-basis? Hard

✅ Ideal answer
  • flex-grow determines how much an item can grow relative to others.
  • flex-shrink determines how much an item can shrink when there isn't enough space.
  • flex-basis defines the initial main-size used before remaining space is distributed.
🔁 Follow-up: What does flex: 1; mean? It's a shorthand that commonly behaves as: flex-grow: 1; flex-shrink: 1; flex-basis: 0%;.

💻 Code

style.css — Visual Studio Code
style.css
.item {
  flex-grow: 1;
  flex-shrink: 1;
  flex-basis: 200px;
}

Q134 — What is the difference between flex-basis: auto and flex-basis: 0? Hard

✅ Ideal answer flex-basis: auto uses the item's main-size property (e.g., width) as the initial basis.

flex-basis: 0 sets the initial flex base to effectively zero, so available free space is distributed based primarily on the flex grow factors.
🔁 Follow-up: If two items have flex: 1; what happens? They generally divide the available free space equally, subject to minimum sizes and other constraints.

💻 Code

style.css — Visual Studio Code
style.css
.item-auto { flex-basis: auto; width: 100px; }
.item-zero { flex-basis: 0; }

Q135 — What does min-width: 0 solve in Flexbox? Hard

✅ Ideal answer Flex items have an automatic minimum size behavior that can sometimes prevent them from shrinking as expected.

Setting min-width: 0; allows the item to shrink below its content's intrinsic minimum size in situations where that default minimum would otherwise cause overflow.
🔁 Follow-up: Where might you encounter this problem in a real application? For example, in a dashboard layout (Sidebar | Main Content). If the main content is a flex child containing a wide table or long text.

💻 Code

style.css — Visual Studio Code
style.css
.main-content {
  flex: 1;
  min-width: 0; /* The Fix */
}

Q136 — What is the difference between gap, margin, and padding in a Flexbox layout? Medium

✅ Ideal answer
  • gap creates consistent spacing between flex or grid items.
  • margin creates space outside an individual element.
  • padding creates space between an element's content and its border.
🔁 Follow-up: Does gap add space around the outer edges of the container? No. gap creates spacing between adjacent items, not between the items and the container's outer edges.

💻 Code

style.css — Visual Studio Code
style.css
.container {
  display: flex;
  gap: 20px;
}

Q137 — What is CSS Grid, and how is it different from Flexbox? Easy → Medium

✅ Ideal answer CSS Grid is a two-dimensional layout system that can control rows and columns simultaneously.

Flexbox is primarily a one-dimensional layout system, focusing on a row or a column at a time.
🔁 Follow-up: Would you use Grid or Flexbox for a navigation bar? Usually Flexbox because navigation is commonly a one-dimensional arrangement. For a page layout with rows and columns, Grid may be more appropriate.

💻 Code

style.css — Visual Studio Code
style.css
.flex-container { display: flex; }
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

Q138 — What does fr mean in CSS Grid? Medium

✅ Ideal answer fr stands for fractional unit. It represents a fraction of the available space in a grid container after accounting for other track sizes and relevant gaps.
🔁 Follow-up: What does grid-template-columns: repeat(3, 1fr); mean? It creates three flexible columns that generally receive equal fractions of the available grid space.

💻 Code

style.css — Visual Studio Code
style.css
.grid {
  display: grid;
  grid-template-columns: 1fr 2fr;
}

Q139 — What is the difference between auto-fit and auto-fill in CSS Grid? Hard

✅ Ideal answer auto-fit collapses empty tracks when possible, allowing existing items to expand and fill the available space.

auto-fill keeps the available track structure, including empty tracks, when they fit.
🔁 Follow-up: Give me a responsive product grid using this concept. grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); - This allows the number of columns to adapt to the available width.

💻 Code

style.css — Visual Studio Code
style.css
.autofit {
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
}
.autofill {
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
}

Q140 — What is minmax() in CSS Grid? Medium → Hard

✅ Ideal answer minmax() defines a minimum and maximum size for a grid track.

Each column should be at least the minimum size, while being allowed to grow up to the maximum size within the available space.
🔁 Follow-up: Why is this better than manually writing media queries? Because the grid can respond continuously to the available space rather than relying on many fixed breakpoints.

💻 Code

style.css — Visual Studio Code
style.css
.grid {
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
}

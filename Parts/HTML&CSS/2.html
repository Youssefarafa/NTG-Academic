Q11 — What is Semantic HTML? Easy

✅ Ideal answer Semantic HTML means using HTML elements according to their meaning and purpose — such as <header>, <nav>, <main>, <section>, <article>, <footer>, and <button> — instead of using <div> for everything. It improves accessibility, SEO, and code readability.
🔁 Follow-up: What's the difference between <div> and <section>? A <section> represents a thematic grouping and usually has a heading. A <div> has no semantic meaning — it's used only as a styling/layout wrapper.
🔁 Follow-up: Why is semantic HTML important? It improves:
• Accessibility
• Maintainability
• Document structure
• SEO understanding
• Integration with assistive technologies

🔁 Follow-up: What is the difference between <header>, <nav>, <main>, <aside>, and <footer>? They are semantic elements that describe different structural parts of a page:
  • <header> represents introductory content for a page or section.
  • <nav> contains major navigation links.
  • <main> contains the primary content of the document.
  • <aside> contains related or supplementary content.
  • <footer> contains footer information for a page or section.
🔁 Follow-up: Can a page have multiple <header> or <footer> elements? Yes. They can be used for the document itself or for individual sections/articles. However, a document should generally have one primary <main> element.

Q12 — What is the difference between <div> and <span>? Easy

✅ Ideal answer <div> is a generic block-level container, while <span> is a generic inline-level container. Use a div to group sections of a layout and a span to style or group a small part of text.
🔁 Follow-up: Can CSS change their default display behavior? Yes. For example, I can make a div inline using display: inline, or make a span block-level using display: block.

💻 Code

index.html — Visual Studio Code
index.html
<!-- div: block-level container -->
<div class="layout-row">Row 1</div>
<div class="layout-row">Row 2</div>

<!-- span: inline container inside text -->
<p>The price is <span class="highlight">$49</span> today only.</p>

<!-- CSS can override the default display -->
<div class="inline-div">div with display:inline</div>
<div class="inline-div">another inline div</div>
<span class="block-span">span with display:block (1)</span>
<span class="block-span">span with display:block (2)</span>

<style>
  .inline-div { display: inline; }
  .block-span { display: block; }
</style>

Q13 — What is the DOM? Easy

✅ Ideal answer The DOM (Document Object Model) is a tree-like representation of the HTML document created by the browser. JavaScript can use the DOM to read, modify, add, or remove elements and attributes.
🔁 Follow-up: Does the DOM equal the HTML source code? Not exactly. The browser parses the HTML and creates the DOM. The DOM can then be modified by JavaScript, so it can differ from the original HTML source.

💻 Code

index.html — Visual Studio Code
index.html
<ul id="list">
  <li>Item 1</li>
</ul>
<button id="addBtn">+ Add item</button>

<script>
  const list = document.getElementById('list');
  const btn  = document.getElementById('addBtn');
  btn.addEventListener('click', () => {
    const li = document.createElement('li');           // create
    li.textContent = `Item ${list.children.length + 1}`; // modify
    list.appendChild(li);                              // add to DOM
  });
</script>

Q14 — What is the difference between id and class? Easy

✅ Ideal answer An id is intended to uniquely identify an element within a document, while a class can be shared by multiple elements. For styling reusable elements, use classes.
🔁 Follow-up: Can multiple elements have the same ID? Technically browsers may still render the page, but IDs must be unique. Using the same ID multiple times is invalid HTML and can cause problems with JavaScript (e.g. getElementById returns only the first match), CSS, and accessibility.

💻 Code

index.html — Visual Studio Code
index.html
<header id="site-header">Site (id = site-header)</header>
<p class="text-muted">First paragraph (class = text-muted)</p>
<p class="text-muted">Second paragraph (class = text-muted)</p>

<!-- ❌ Invalid: duplicate IDs -->
<div id="box" class="box">A (id="box")</div>
<div id="box" class="box">B (id="box" — duplicate!)</div>

<style>
  #site-header { background: #4f46e5; color: #fff; padding: 8px 14px; }
  .text-muted  { color: #888; }
  .box         { background: #fecaca; padding: 6px; margin: 4px 0; }
</style>

Q15 — What is the difference between block, inline, and inline-block? Easy

✅ Ideal answer
  • block: starts on a new line and takes the available width.
  • inline: stays in the text flow; width/height generally ignored.
  • inline-block: stays inline but respects width and height.
🔁 Follow-up: Give examples. div is normally block, span is normally inline, and button behaves like inline-block.

💻 Code

index.html — Visual Studio Code
index.html
<div class="row">
  <strong>block:</strong>
  <div class="block">div.block — full width, new line</div>
</div>

<div class="row">
  <strong>inline:</strong>
  <span class="inline">span (width:200px ignored)</span>
  <span class="inline">second span</span>
</div>

<div class="row">
  <strong>inline-block:</strong>
  <span class="inline-block">120×60</span>
  <span class="inline-block">120×60</span>
</div>

<style>
  .block        { display: block; background: #fdd; padding: 6px; }
  .inline       { display: inline; background: #dfd; padding: 6px; width: 200px; height: 50px; }
  .inline-block { display: inline-block; background: #ddf; width: 120px; height: 60px; padding: 6px; }
</style>

Q16 — What is the CSS Box Model? Easy

✅ Ideal answer Every element is a box made of: content → padding → border → margin.
Content holds the content, padding is space inside the border, border surrounds the element, margin is space outside.
🔁 Follow-up: What does box-sizing: border-box do? It makes the declared width and height include content, padding, and border.

💻 Code

index.html — Visual Studio Code
index.html
<div class="box">content-box — total = 250px</div>
<div class="box border-box">border-box — total = 200px</div>

<style>
  .box {
    width: 200px;
    padding: 20px;
    border: 5px solid #333;
    margin: 15px;
    background: #cfe;
    box-sizing: content-box;   /* 200 + 40 + 10 = 250px */
  }
  .box.border-box {
    background: #fcd;
    box-sizing: border-box;    /* total = 200px */
  }
</style>

Q17 — What is CSS specificity? Easy → Medium

✅ Ideal answer Specificity decides which CSS rule wins when multiple rules target the same element.
inline styles > IDs > classes / attributes / pseudo-classes > element selectors.
🔁 Follow-up: What is more specific — .button or #button? #button — an ID (0,1,0,0) beats a class (0,0,1,0).

💻 Code

index.html — Visual Studio Code
index.html
<button id="save" class="btn">Save (green — id wins)</button>
<button id="button" class="button">Red wins</button>

<style>
  /* 3 rules → the id wins (green) */
  button  { background: gray; }   /* 0,0,1  */
  .btn    { background: blue; }   /* 0,1,0  */
  #save   { background: green; }  /* 1,0,0 ← wins */

  /* #button beats .button */
  .button { color: blue; }   /* 0,1,0 */
  #button { color: red;  }   /* 1,0,0 ← wins */
</style>

Q18 — What is Flexbox? Easy

✅ Ideal answer Flexbox is a one-dimensional layout system that arranges elements along a row or column. Properties: display: flex, justify-content, align-items, flex-direction, gap, flex-wrap.
🔁 Follow-up: What is the difference between justify-content and align-items? Their effect depends on flex direction. justify-content distributes along the main axis; align-items aligns along the cross axis.

💻 Code

index.html — Visual Studio Code
index.html
<nav class="navbar">
  <span class="logo">Logo</span>
  <a href="#">Home</a>
  <a href="#">About</a>
  <a href="#">Contact</a>
</nav>

<style>
  .navbar {
    display: flex;
    flex-direction: row;
    justify-content: space-between; /* main axis  */
    align-items: center;            /* cross axis */
    gap: 16px;
    flex-wrap: wrap;
    padding: 12px;
    background: #f5f5f5;
    border-radius: 8px;
  }
  .navbar a    { color: #4f46e5; text-decoration: none; }
  .navbar .logo { font-weight: bold; }
</style>

Q19 — What is CSS Grid? Easy

✅ Ideal answer CSS Grid is a two-dimensional layout system that works with rows and columns — useful for complex page layouts and structured grids.
🔁 Follow-up: Flexbox or Grid for a product grid? Either works, but Grid is natural for explicit row/column control. Flexbox is better for one-dimensional layouts (nav bars, toolbars).

💻 Code

index.html — Visual Studio Code
index.html
<div class="product-grid">
  <div class="card">1</div>
  <div class="card">2</div>
  <div class="card">3</div>
  <div class="card">4</div>
  <div class="card">5</div>
</div>

<div class="toolbar">
  <span>Toolbar (Flexbox):</span>
  <button>Save</button>
  <button>Cancel</button>
</div>

<style>
  .product-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 16px;
  }

  .toolbar { display: flex; align-items: center; gap: 12px; margin-top: 16px; background: #eef; padding: 10px; border-radius: 8px; }
</style>

Q20 — What is Responsive Design? Easy

✅ Ideal answer Responsive design builds interfaces that adapt to different screen sizes — using flexible layouts, Grid/Flexbox, relative units, media queries, responsive images, and breakpoints.
🔁 Follow-up: How would you make an Angular dashboard responsive? Build a flexible layout with Grid/Flexbox, introduce breakpoints for major layout changes, and use responsive UI-library components when appropriate.

💻 Code

index.html — Visual Studio Code
index.html
<div class="dashboard">
  <aside class="sidebar">Sidebar</aside>
  <main class="content">
    Content
    <div class="cards">
      <div class="q10-card">A</div>
      <div class="q10-card">B</div>
      <div class="q10-card">C</div>
    </div>
  </main>
</div>

<style>
  .dashboard {
    display: grid;
    grid-template-columns: 240px 1fr;
    gap: 16px;
    background: #eef;
    padding: 16px;
    border-radius: 8px;
  }
  .sidebar { background: #4f46e5; color: #fff; padding: 16px; border-radius: 8px; }
  .content { background: #fff; padding: 16px; border-radius: 8px; }
  .cards {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(120px, 1fr));
    gap: 12px; margin-top: 12px;
  }
  .q10-card { background: #dcfce7; padding: 16px; border-radius: 8px; text-align: center; }

  @media (max-width: 768px) {
    .dashboard { grid-template-columns: 1fr; }
  }
</style>

Q111 — What is CSS and what problem does it solve? Easy

✅ Ideal answer CSS stands for Cascading Style Sheets. It is used to control the presentation and layout of web documents.

HTML defines the structure and meaning of the content, while CSS controls things such as: colors, fonts, spacing, layout, responsive design, animations, and visual appearance.
🔁 Follow-up: Can we build a website without CSS? Yes. HTML can create the structure and content, but the page will rely mostly on the browser's default styles and won't have the intended visual design.

Q112 — What does "Cascading" mean in CSS? Easy → Medium

✅ Ideal answer The cascade is the process the browser uses to determine which CSS declarations should apply when multiple rules target the same element.

The result depends on factors such as: origin and importance, cascade layers, specificity, and source order.
🔁 Follow-up: Does the last CSS rule always win? No. Source order is only one factor. A more specific selector or a declaration with different cascade priority can win even if it appears earlier.

💻 Code

style.css

  color: red;
}

p {
  color: blue; /* This wins because it comes later */
}

Q113 — What are the three main ways to apply CSS? Easy

✅ Ideal answer There are three common ways:
  1. Inline CSS: <p style="color: red;">
  2. Internal CSS: Using a <style> tag in the <head>.
  3. External CSS: Using a <link rel="stylesheet"> tag.
External stylesheets are generally preferred for maintainability and reuse.
🔁 Follow-up: Which approach is generally best for a large application? External stylesheets or a well-structured CSS architecture are generally preferable because they improve reuse, maintainability, and separation of concerns.

💻 Code

index.html
<!-- 1. Inline -->
<p style="color: red;">Text</p>

<!-- 2. Internal -->
<style>
  p { color: red; }
</style>

<!-- 3. External -->
<link rel="stylesheet" href="styles.css">

Q114 — What is a CSS selector? Easy

✅ Ideal answer A CSS selector identifies the elements to which a CSS rule applies.

CSS supports different types of selectors, including: element selectors, class selectors, ID selectors, attribute selectors, combinators, pseudo-classes, and pseudo-elements.
🔁 Follow-up: What does the selector .card p mean? It selects p elements that are descendants of an element with the class card.

Q115 — What is the difference between *, element, class, and ID selectors? Easy

✅ Ideal answer
  • Universal (*): Targets all elements.
  • Element (p): Targets all specific tags.
  • Class (.card): Targets elements with that class.
  • ID (#header): Targets the unique element with that ID.
🔁 Follow-up: Can multiple elements have the same class? Yes. That's one of the main purposes of classes.

💻 Code

style.css

p { color: red; }
.card { padding: 20px; }
#header { height: 60px; }

Q116 — What is the difference between descendant and child selectors? Medium

✅ Ideal answer The descendant selector uses a space (e.g., .container p). It selects any p descendant inside .container.

The child selector uses > (e.g., .container > p). It selects only p elements that are direct children of .container.
🔁 Follow-up: Which is more restrictive? The child selector > because it requires a direct parent-child relationship.

💻 Code

style.css — Visual Studio Code
style.css
.container p { color: red; }   /* Descendant */
.container > p { color: blue; }  /* Child */

Q117 — What is the difference between :first-child, :first-of-type, and :nth-child()? Medium

✅ Ideal answer
  • :first-child selects an element if it is the first child of its parent.
  • :first-of-type selects the first sibling of that particular element type.
  • :nth-child(n) selects an element based on its position among its parent's children.
🔁 Follow-up: Given a div with an h2 followed by two p tags, will p:first-child select the first paragraph? No, because the first child of the div is the <h2>, not the <p>. But p:first-of-type would select the first <p>.

💻 Code

style.css
li:first-child { color: red; }
p:first-of-type { color: blue; }
li:nth-child(2) { background: yellow; }

Q118 — What is CSS inheritance? Medium

✅ Ideal answer Inheritance means that some CSS properties can automatically take their computed value from an ancestor when no value is specified on the descendant.

Properties like color, font-family, and font-size are commonly inherited.
🔁 Follow-up: Can I explicitly control inheritance? Yes. CSS provides keywords such as inherit, initial, unset, revert.

💻 Code

Q119 — What is the difference between inherit, initial, unset, and revert? Hard

✅ Ideal answer
  • inherit: Forces the property to take the computed value from the parent.
  • initial: Resets the property to its CSS-defined initial value.
  • unset: Acts as inherit for inherited properties and initial for non-inherited properties.
  • revert: Rolls the property's value back to a previous level of the cascade.
🔁 Follow-up: What is the difference between initial and inherit? initial uses the property's defined initial value, while inherit explicitly takes the value from the parent.

💻 Code

style.css — Visual Studio Code
style.css
.inherit { color: inherit; }
.initial { color: initial; }
.unset { color: unset; }
.revert { color: revert; }

Q120 — What is the difference between display: none, visibility: hidden, and opacity: 0? Medium

✅ Ideal answer
  • display: none: The element is removed from the layout. It doesn't occupy space.
  • visibility: hidden: The element is visually hidden but normally remains in the layout.
  • opacity: 0: The element becomes fully transparent but still participates in layout.
🔁 Follow-up: Which one would you use for a fade-out animation? opacity is often suitable because it can be animated smoothly.

💻 Code

style.css — Visual Studio Code
style.css
.hidden-display { display: none; }
.hidden-visibility { visibility: hidden; }
.hidden-opacity { opacity: 0; }

Q121 — What is the difference between content-box and border-box? Easy → Medium

✅ Ideal answer content-box is the default box-sizing behavior. The declared width and height apply only to the content area.

With border-box, the declared width and height include the content, padding, and border.
🔁 Follow-up: What would the actual outer width be with content-box? (width: 200px, padding: 20px, border: 5px) 200px + 40px + 10px = 250px.

💻 Code

style.css — Visual Studio Code
style.css
.box {
  width: 150px;
  padding: 20px;
  border: 5px solid;
  box-sizing: border-box; /* Total width remains 150px */
}

Q122 — What does box-sizing: border-box solve? Easy → Medium

✅ Ideal answer It makes width and height calculations more predictable because padding and borders are included within the declared dimensions.

A common global rule is: *, *::before, *::after { box-sizing: border-box; }.
🔁 Follow-up: Does this change the CSS specification's default box-sizing? No. It overrides the property for the selected elements. The default for most elements is still content-box.

💻 Code

style.css — Visual Studio Code
style.css
*,
*::before,
*::after {
  box-sizing: border-box;
}

Q123 — Explain position: static, relative, absolute, fixed, and sticky. Medium

✅ Ideal answer
  • static: The default. Participates in normal flow.
  • relative: Remains in normal flow but can be visually offset.
  • absolute: Removed from normal flow. Positioned relative to its nearest positioned ancestor.
  • fixed: Positioned relative to the viewport. Doesn't move when scrolling.
  • sticky: Behaves like relative until a scroll threshold is reached, then acts like fixed.
🔁 Follow-up: Why do we often write `.parent { position: relative; } .child { position: absolute; }`? Because the positioned parent becomes the containing block for the absolutely positioned child.

💻 Code

style.css — Visual Studio Code
style.css
.static { position: static; }
.relative { position: relative; top: 10px; left: 10px; }
.absolute { position: absolute; top: 0; right: 0; }
.fixed { position: fixed; bottom: 20px; right: 20px; }
.sticky { position: sticky; top: 0; }

Q124 — What is the difference between relative positioning and absolute positioning? Medium

✅ Ideal answer relative keeps the element in the normal document flow while allowing visual offset.

absolute removes the element from normal flow and positions it relative to its containing block.
🔁 Follow-up: If I move a relative element using top: 20px, does its original space disappear? No. Its original space remains reserved because it is still part of normal flow.

💻 Code

style.css — Visual Studio Code
style.css
.relative { position: relative; top: 10px; }
.absolute { position: absolute; top: 10px; }

Q125 — What is overflow, and what is the difference between visible, hidden, scroll, and auto? Medium

✅ Ideal answer overflow controls what happens when content exceeds an element's box.
  • visible: Content extends outside.
  • hidden: Content is clipped.
  • scroll: Scrollbars are always present.
  • auto: Scrollbars appear only when necessary.
🔁 Follow-up: What is the difference between overflow-x and overflow-y? They control horizontal and vertical overflow independently.

💻 Code

style.css — Visual Studio Code
style.css
.box-visible { overflow: visible; }
.box-hidden { overflow: hidden; }
.box-scroll { overflow: scroll; }
.box-auto { overflow: auto; }

Q126 — What is the difference between overflow: hidden and clip? Hard

✅ Ideal answer Both can prevent overflowing content from being visible, but clip is more specifically about clipping and does not create a scroll container in the same way that overflow: hidden can.
🔁 Follow-up: Would overflow: clip allow the user to scroll the element programmatically? No. clip prevents scrolling of the clipped overflow completely.

💻 Code

style.css — Visual Studio Code
style.css
.box {
  overflow: clip;
}

Q127 — What is margin collapsing? Medium

✅ Ideal answer Margin collapsing is a CSS layout behavior where vertical margins of certain block-level elements can combine rather than simply add together.
🔁 Follow-up: How can you sometimes prevent margin collapsing? Adding padding or border to the parent, creating a new formatting context (like display: flow-root), or using Flexbox/Grid.

💻 Code

style.css — Visual Studio Code
style.css
.first { margin-bottom: 30px; }
.second { margin-top: 20px; }
/* Resulting gap is 30px, not 50px */

Q128 — What is a Block Formatting Context (BFC)? Hard

✅ Ideal answer A Block Formatting Context is a layout context in which block-level boxes are laid out according to specific block formatting rules.

Creating a BFC can affect float interaction, margin collapsing, and containment of floated descendants. A modern way to create one is display: flow-root;.
🔁 Follow-up: Why might display: flow-root be useful? It can contain floated children and prevent layout issues without needing the old clearfix hack.

💻 Code

style.css — Visual Studio Code
style.css
.container {
  display: flow-root;
}

Q129 — What was the traditional clearfix technique used for? Medium → Hard

✅ Ideal answer When elements are floated, their parent can fail to contain them. A clearfix used a pseudo-element to force the parent to contain the floats.
🔁 Follow-up: Would you use floats to build a modern dashboard layout? Usually no. I'd prefer Flexbox or CSS Grid.

💻 Code

style.css — Visual Studio Code
style.css
.clearfix::after {
  content: "";
  display: table;
  clear: both;
}

Q130 — What is Flexbox and when would you use it? Easy → Medium

✅ Ideal answer Flexbox is a one-dimensional CSS layout system designed to arrange items along a row or a column.

I would commonly use Flexbox for: navigation bars, aligning buttons, centering content, and distributing space.
🔁 Follow-up: What is the difference between the main axis and cross axis? The main axis is determined by flex-direction. The cross axis is perpendicular to it.

💻 Code

style.css — Visual Studio Code
style.css
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

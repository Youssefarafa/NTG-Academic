CSS Grid — Complete Guide

Every CSS Grid property, with a quick definition, syntax, values, and a live example. Use the sidebar to jump between properties.

display

Defines the element as a grid container.

display: grid | inline-grid

A grid container establishes a grid formatting context for its direct children. grid is block-level; inline-grid is inline-level.

Syntax

.container {
  display: grid; /* or inline-grid */
  gap: 8px;
}

Example

grid vs inline-grid

grid-template-columns

Defines the column tracks of a grid.

grid-template-columns: none | <track-list>

Sets the number of columns and the width of each. Supports px, %, fr, auto, repeat(), minmax().

Syntax

.container {
  grid-template-columns: 1fr 2fr 1fr;
  grid-template-columns: repeat(3, 1fr);
  grid-template-columns: repeat(3, minmax(100px, 1fr));
}

Values

1fr 2fr 1fr
Three columns; middle takes double the available space.
repeat(3, 1fr)
Shorthand to repeat a track pattern N times.
minmax(100px, 1fr)
Column is at least 100px, at most 1 fraction of free space.
auto
Sized by content, then stretched if free space exists.

grid-template-areas

Names grid regions for easy item placement.

grid-template-areas: none | <string>+

Each string is a row of the grid. Use grid-area: name on items to place them. A dot . = empty cell.

Syntax

.container {
  grid-template-areas:
    "header  header  header"
    "sidebar main    aside"
    "footer  footer  footer";
}
.header { grid-area: header; }

justify-items

Aligns items along the inline (horizontal) axis.

justify-items: start | center | end | stretch

Applies alignment to every item inside its own cell along the inline axis. The dashed box below shows the full cell, the solid block shows the item.

Syntax

.container {
  justify-items: center;
}

Values

start
Packs items to the start of the inline axis.
center
Centers items horizontally inside their cells.
end
Packs items to the end of the inline axis.
stretch
Fills the cell along the inline axis (default for grid items).

grid-auto-flow

Controls auto-placement direction.

grid-auto-flow: row | column | row dense | column dense

Determines how items without a defined position are placed. dense backfills earlier gaps.

Syntax

.container {
  grid-auto-flow: row;
  grid-auto-flow: column;
  grid-auto-flow: row dense;
}

Values

row
Fill each row before moving to the next.
column
Fill each column before moving to the next.
row dense
Row flow, but backfill earlier gaps with smaller items.
column dense
Column flow, with gap backfilling.

grid

Shorthand for every explicit and implicit grid property.

grid: <grid-template> | <grid-auto-flow> <grid-auto-rows> / <grid-auto-columns>

Combines grid-template, grid-auto-flow, grid-auto-rows, and grid-auto-columns.

Syntax

.container {
  grid: auto-flow dense 60px / repeat(3, 1fr);
  /* = grid-auto-flow: row dense;
       grid-auto-rows: 60px;
       grid-template-columns: repeat(3, 1fr); */
}

grid-column-start / grid-column-end

Places an item horizontally by line number.

grid-column-start: <line> | span <n>

Defines the start and end column lines of a grid item. Lines are counted from 1, or from the end with negative values.

  grid-column-end: 4;

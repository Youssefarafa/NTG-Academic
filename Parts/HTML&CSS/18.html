Q171 — Explain the CSS Box Model. Easy

✅ Ideal answer The CSS box model describes how the browser calculates an element's dimensions. It consists of: Content → Padding → Border → Margin.

With the default content-box, the declared width: 200px applies to the content only. The total rendered width is 200 (content) + 40 (padding) + 10 (border) = 250px. Margin is outside the element's box.
🔁 Follow-up: What changes when you use `box-sizing: border-box;`? The declared width includes the content, padding, and border. So width: 200px means the total border-box width is exactly 200px.

💻 Code

style.css — Visual Studio Code
style.css
.box {
  width: 150px;
  padding: 20px;
  border: 5px solid;
  margin: 10px;
}

Q172 — What is the difference between content-box and border-box? Medium

✅ Ideal answer With content-box, the declared width/height applies to the content area.

With border-box, the declared width/height includes the content + padding + border.

A common practice is to apply *, *::before, *::after { box-sizing: border-box; } to make sizing more predictable.
🔁 Follow-up: Does border-box include margin? No. Margin remains outside the border box.

💻 Code

style.css — Visual Studio Code
style.css
*,
*::before,
*::after {
  box-sizing: border-box;
}

Q173 — What is margin collapsing? Hard

✅ Ideal answer Margin collapsing is a behavior where vertical margins of certain block-level elements can combine rather than simply adding together.

If a box has margin-bottom: 30px and the next has margin-top: 20px, the resulting gap can be 30px (not 50px). It occurs between adjacent block siblings, parent/child in certain conditions, and empty blocks.
🔁 Follow-up: Does horizontal margin collapse? No. Margin collapsing is primarily a behavior of vertical margins in normal block flow.

💻 Code

style.css — Visual Studio Code
style.css
.first { margin-bottom: 40px; }
.second { margin-top: 20px; }
/* Resulting gap is 40px, not 60px */

Q174 — What is the difference between display: none, visibility: hidden, and opacity: 0? Medium

✅ Ideal answer
  • display: none: Removed from layout. Doesn't occupy space.
  • visibility: hidden: Invisible but still occupies space.
  • opacity: 0: Fully transparent but remains in layout and can still potentially participate in interaction/hit testing.
🔁 Follow-up: Which one would you use to completely remove an element from layout? display: none.

💻 Code

style.css — Visual Studio Code
style.css
.hidden-display { display: none; }
.hidden-visibility { visibility: hidden; }
.hidden-opacity { opacity: 0; }

Q175 — Explain the CSS position values: static, relative, absolute, fixed, and sticky. Medium

✅ Ideal answer
  • static: The default. top/left don't apply.
  • relative: Remains in normal flow, but can be visually offset. Establishes a containing block.
  • absolute: Removed from flow. Positioned relative to the nearest positioned ancestor.
  • fixed: Positioned relative to the viewport.
  • sticky: Behaves relatively until a scroll threshold is reached, then sticks.
🔁 Follow-up: Why do developers commonly write `.parent { position: relative; } .child { position: absolute; }`? Because the positioned ancestor establishes the containing block that the absolutely positioned child uses for its offsets.

💻 Code

style.css — Visual Studio Code
style.css
.parent { position: relative; }
.child { position: absolute; top: 0; right: 0; }
.fixed { position: fixed; bottom: 20px; right: 20px; }
.sticky { position: sticky; top: 0; }

Q176 — How does position: sticky actually work? Hard

✅ Ideal answer position: sticky combines aspects of relative positioning and scrolling behavior. The element participates in normal flow, then sticks relative to its scrolling container when it reaches the specified threshold (like top: 0).
🔁 Follow-up: Why might position: sticky appear not to work? Common causes include: no offset specified (like top), the container doesn't provide enough scrollable space, an ancestor establishes a different scrolling context, or overflow settings on ancestors change the relevant scroll container.

💻 Code

style.css — Visual Studio Code
style.css
.header {
  position: sticky;
  top: 0; /* Required for sticky to work */
}

Q177 — What is the difference between overflow: hidden, auto, scroll, and clip? Medium → Hard

✅ Ideal answer
  • hidden: Clips overflowing content (no scrollbar).
  • auto: Provides scrolling when needed.
  • scroll: Provides scrolling mechanism regardless of overflow.
  • clip: Clips overflow without providing a scrolling mechanism (like hidden, but more strict).
🔁 Follow-up: What's a common downside of using overflow: hidden carelessly? It can unintentionally clip content, and in some layouts it can also affect scrolling/sticky behavior depending on which axis and ancestor is involved.

💻 Code

style.css — Visual Studio Code
style.css
.box { overflow: hidden; }
.box { overflow: auto; }
.box { overflow: scroll; }
.box { overflow: clip; }

Q178 — What is the difference between display: block, inline, and inline-block? Easy

✅ Ideal answer
  • block: Starts on a new line, takes full width (e.g., div, p).
  • inline: Flows within text, ignores width/height (e.g., span, a).
  • inline-block: Flows inline, but accepts width and height.
🔁 Follow-up: Can you set width and height on an inline element? Not in the same effective way as a block or inline-block; width and height generally don't control the inline box.

💻 Code

style.css — Visual Studio Code
style.css
.block { display: block; }
.inline { display: inline; }
.inline-block { display: inline-block; width: 200px; }

Q179 — What is the difference between overflow-wrap, word-break, and white-space? Hard

✅ Ideal answer
  • overflow-wrap: Controls whether unbreakable strings can be broken to prevent overflow.
  • word-break: Controls how words can break across lines.
  • white-space: Controls how whitespace and line wrapping are handled (e.g., nowrap prevents wrapping).
🔁 Follow-up: Suppose you have a long unbroken string inside a small card. What would you consider? I could use overflow-wrap: anywhere; or an appropriate word-break strategy depending on the content and desired behavior.

💻 Code

style.css — Visual Studio Code
style.css
.box { overflow-wrap: anywhere; }
.box { word-break: break-word; }
.box { white-space: nowrap; }

Q180 — What is the difference between overflow: hidden and text truncation with ellipsis? Medium

✅ Ideal answer overflow: hidden simply clips overflowing content.

For single-line text truncation with an ellipsis, you need three properties together: white-space: nowrap;, overflow: hidden;, and text-overflow: ellipsis;.
🔁 Follow-up: Why isn't overflow: hidden alone enough to produce ...? Because overflow: hidden only clips the content. text-overflow: ellipsis is the property responsible for indicating truncated text with an ellipsis.

💻 Code

style.css — Visual Studio Code
style.css
.single-line {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

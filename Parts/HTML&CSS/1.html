Q1 — What is HTML? Easy

✅ Ideal answer HTML stands for HyperText Markup Language. It is the standard markup language used to structure content on web pages.

It defines the structure and meaning of content using elements such as headings, paragraphs, and links.

HTML itself is not a programming language because it doesn't contain programming logic like loops, conditions, or functions.
🔁 Follow-up: What are CSS and JavaScript used for? • HTML → Structure / semantics
• CSS → Presentation / styling
• JavaScript → Behavior / logic

Q2 — What is an HTML element? Easy

✅ Ideal answer An HTML element is a complete unit of HTML structure. It can contain an opening tag, content, and a closing tag.

The complete structure is the element.
🔁 Follow-up: Are all HTML elements made of opening and closing tags? No. Some are void elements and don't have closing tags — for example: <img>, <input>, <br>, <hr>, <meta>, <link>.

Q3 — What is the difference between an HTML tag and an HTML element? Easy

✅ Ideal answer A tag is the markup syntax itself (e.g., <p>).

An element is the complete structure, including the opening tag, content, and closing tag (e.g., <p>Hello</p>).
🔁 Follow-up: What about <img src="cat.jpg">? <img> is a void element, so there is no closing </img> tag.
🔁 Follow-up: Can an element have multiple attributes? Yes. For example: <img src="plant.jpg" alt="Green plant" width="300">.

Q4 — What is the basic structure of an HTML document? Easy

✅ Ideal answer An HTML document has a root <html> element with two main children: <head> and <body>.

<head> contains metadata and resources.
<body> contains the page content.
🔁 Follow-up: Is content inside <head> displayed as normal page content? Generally no. The head contains document metadata, the title, links to resources, and scripts/configuration.
🔁 Follow-up: Where would you put a CSS file? Using <link rel="stylesheet" href="styles.css">, usually inside <head>.

💻 Code

index.html — Visual Studio Code
index.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Page</title>
  <link rel="stylesheet" href="styles.css">
</head>

<body>
  <h1>Hello</h1>
</body>
</html>

Q5 — Why is the lang attribute important? Easy

✅ Ideal answer The lang attribute specifies the language of the document or element.

For English: <html lang="en">
For Arabic: <html lang="ar">

It helps browsers, search engines, translation tools, and assistive technologies understand the language correctly.
🔁 Follow-up: Can you change language for only part of a page? Yes. For example: <p>Hello <span lang="ar">مرحبا</span></p>.

💻 Code

index.html — Visual Studio Code
index.html
<html lang="en">
  <body>
    <p>
      Hello
      <span lang="ar" dir="rtl">مرحبا</span>
    </p>
  </body>
</html>

Q6 — What are void elements in HTML? Easy → Medium

✅ Ideal answer Void elements are HTML elements that cannot have child content and don't use a closing tag.

Examples: <img>, <input>, <br>, <hr>, <meta>, <link>, <source>, <area>, <base>, <embed>, <param>, <track>, <wbr>.
🔁 Follow-up: What about <input />? The slash is allowed in HTML syntax but doesn't make the element "more void". The element is already a void element.

Q7 — What is the difference between HTML entities and normal characters? Medium

✅ Ideal answer HTML character references (entities) allow us to represent characters that have special meaning in HTML, or characters that are hard to type directly.

Examples: &lt;, &gt;, &amp;, &quot;, &nbsp;.
🔁 Follow-up: Why can't we simply write < inside normal text? Because < has special meaning in HTML and could be interpreted as the start of a tag.

Q8 — What is the difference between absolute and relative URLs in HTML? Medium

✅ Ideal answer An absolute URL contains the complete address (protocol + host + path).

A relative URL is resolved relative to the current document or base URL.
🔁 Follow-up: What's the difference between /about and about? /about is root-relative (resolved from the site root). about is document-relative (resolved from the current URL's folder).

💻 Code

index.html — Visual Studio Code
index.html
<!-- Absolute -->
<a href="https://example.com/about">About</a>

<!-- Root-relative -->
<a href="/about">About</a>

<!-- Document-relative -->
<a href="about.html">About</a>
<a href="../images/photo.jpg">Photo</a>

Q9 — What are the different types of <input>? Easy → Medium

✅ Ideal answer HTML provides many input types, including: text, email, password, number, tel, url, search, date, time, datetime-local, month, week, checkbox, radio, file, color, range, hidden, submit, reset, button.

Using the appropriate type gives the browser semantics and built-in validation, and can show a better UI on devices.
🔁 Follow-up: Why use type="email" instead of type="text" for an email field? It provides email-specific semantics and validation, and on some devices it produces a more appropriate keyboard.

<input type="checkbox">

<input type="range">
<input type="color">

Q10 — What is the difference between <table>, <thead>, <tbody>, <tfoot>, and <tr>? Easy → Medium

✅ Ideal answer
  • <table> → the entire table
  • <thead> → header section
  • <tbody> → main data section
  • <tfoot> → footer/summary section
  • <tr> → a table row
  • <th> → header cell
  • <td> → data cell
🔁 Follow-up: What's the difference between <th> and <td>? <th> is a header cell (bold and centered by default), while <td> is a data cell.

💻 Code

    </tr>
  </tbody>

    <tr>

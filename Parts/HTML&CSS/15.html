Q141 — What is the difference between grid-template-columns and grid-auto-columns? Medium

✅ Ideal answer grid-template-columns defines the columns that are explicitly created in the grid.

grid-auto-columns controls the size of columns that the browser creates automatically when items require implicit columns.
🔁 Follow-up: What's the difference between explicit and implicit grid? The explicit grid is the grid tracks defined using properties like grid-template-columns. The implicit grid consists of additional tracks created automatically by the browser when items overflow.

💻 Code

style.css — Visual Studio Code
style.css
.grid {
  display: grid;
  grid-template-columns: 100px 100px; /* Explicit */
  grid-auto-columns: 150px; /* Implicit (red boxes) */
  grid-auto-flow: column;
}

Q142 — What is the difference between grid-template-rows and grid-auto-rows? Medium

✅ Ideal answer grid-template-rows explicitly defines the grid's rows.

grid-auto-rows defines the size of automatically generated implicit rows.
🔁 Follow-up: Why might grid-auto-rows: minmax(100px, auto) be useful? It allows automatically generated rows to have a minimum height while still growing to accommodate their content.

💻 Code

style.css — Visual Studio Code
style.css
.grid {
  display: grid;
  grid-template-rows: 50px 50px; /* Explicit */
  grid-auto-rows: 80px; /* Implicit (red boxes) */
}

Q143 — What is the difference between grid-column, grid-row, and grid-area? Medium

✅ Ideal answer grid-column controls where an item starts and ends across grid columns (e.g., grid-column: 1 / 3;).

grid-row does the same for rows.

grid-area can specify row and column placement using four values: row-start / column-start / row-end / column-end.
🔁 Follow-up: Can grid-area also be used with named grid areas? Yes. When combined with grid-template-areas, you can assign an item to a named region (e.g., grid-area: header;).

💻 Code

style.css — Visual Studio Code
style.css
.item-span {
  grid-column: 1 / 3; /* Spans 2 columns */
  grid-row: 1 / 3;    /* Spans 2 rows */
}

.item-area {
  grid-area: 3 / 1 / 4 / 4; /* row-start / col-start / row-end / col-end */
}

Q144 — What is grid-template-areas and when would you use it? Medium

✅ Ideal answer grid-template-areas allows us to define named regions of a CSS Grid using a visual string representation.

This can make complex page layouts easier to understand and maintain.
🔁 Follow-up: Can you change the layout for mobile? Yes. You can redefine the template in a media query to stack the areas (e.g., "header" "main" "sidebar" "footer").

💻 Code

style.css — Visual Studio Code
style.css
.layout {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  grid-template-columns: 200px 1fr;
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }

Q145 — What is the difference between justify-items, align-items, justify-content, and align-content in CSS Grid? Hard

✅ Ideal answer
  • justify-items / align-items: Aligns the items inside their individual grid cells (inline / block axis).
  • justify-content / align-content: Distributes the entire grid track structure within the container when there is extra space.
🔁 Follow-up: What's the equivalent of align-self in Grid? Grid also supports align-self and justify-self for controlling the alignment of an individual grid item.

💻 Code

style.css — Visual Studio Code
style.css
.grid {
  display: grid;
  /* Moves the whole grid to the center */
  justify-content: center;
  align-content: center;
  
  /* Moves the items inside their cells */
  justify-items: center;
  align-items: center;
}

Q146 — What is the difference between justify-self and justify-items? Medium

✅ Ideal answer justify-items is set on the grid container and defines the default inline-axis alignment for all grid items.

justify-self is set on an individual grid item and overrides the container's setting for that item.
🔁 Follow-up: Can Flexbox use justify-self in the same way Grid does? No. justify-self is primarily associated with Grid; it doesn't provide the same per-item main-axis behavior in Flexbox.

💻 Code

style.css — Visual Studio Code
style.css
.grid { justify-items: center; }
.special { justify-self: end; }

Q147 — What is a media query? Easy

✅ Ideal answer A media query allows CSS rules to be applied conditionally based on characteristics of the user's environment, such as viewport width, orientation, or user preferences.
🔁 Follow-up: Is responsive design just media queries? No. Responsive design also uses flexible layouts, percentages, Flexbox, Grid, minmax(), relative units, fluid typography, and responsive images. Media queries are only one part.

💻 Code

style.css — Visual Studio Code
style.css
@media (max-width: 768px) {
  .sidebar {
    display: none;
  }
}

Q148 — What is mobile-first responsive design? Medium

✅ Ideal answer Mobile-first means designing the base styles for smaller screens first, then progressively enhancing the layout for larger screens using min-width media queries.
🔁 Follow-up: What's the opposite approach? Desktop-first typically starts with larger-screen styles and uses max-width media queries to adjust the layout for smaller screens.

💻 Code

style.css — Visual Studio Code
style.css
/* Mobile Base */
.container { display: block; }

/* Desktop Enhancement */
@media (min-width: 768px) {
  .container { display: flex; }
}

Q149 — What is the difference between min-width and max-width media queries? Medium

✅ Ideal answer @media (min-width: 768px) applies when the viewport is at least 768px wide (used in mobile-first).

@media (max-width: 767px) applies when the viewport is at most 767px wide (used in desktop-first).
🔁 Follow-up: Can you use both in the same stylesheet? Yes. The important thing is to structure the rules clearly and avoid unnecessary overlapping breakpoints.

💻 Code

style.css — Visual Studio Code
style.css
@media (min-width: 768px) { /* Mobile-first */ }
@media (max-width: 767px) { /* Desktop-first */ }

Q150 — What are CSS functions such as calc(), min(), max(), and clamp()? Medium → Hard

✅ Ideal answer
  • calc() allows arithmetic expressions.
  • min() chooses the smallest value from its arguments.
  • max() chooses the largest value.
  • clamp(min, preferred, max) defines a minimum, preferred, and maximum value.
This is useful for fluid responsive designs.
🔁 Follow-up: Explain `font-size: clamp(16px, 2vw, 32px);` The font size should not go below 16px, can scale according to 2vw, and should not exceed 32px. It scales fluidly within those limits.

💻 Code

style.css — Visual Studio Code
style.css
.calc-box { width: calc(100% - 40px); }
.clamp-box { font-size: clamp(1rem, 4vw, 2rem); }

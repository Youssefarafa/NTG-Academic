Q201 — What are CSS Custom Properties, and how are they different from Sass variables? Medium

✅ Ideal answer CSS Custom Properties are variables managed by the browser at runtime.

Unlike Sass variables, CSS Custom Properties remain available in the generated CSS and can be changed at runtime (e.g., for theming).
🔁 Follow-up: Can an Angular application change a CSS custom property dynamically? Yes. We can modify custom properties through Angular bindings (e.g., [style.--primary-color]="color") or JavaScript.

💻 Code

style.css — Visual Studio Code
style.css
:root {
  --primary-color: #2563eb;
  --spacing-md: 16px;
}

.dark-theme {
  --primary-color: white;
}

.button {
  color: var(--primary-color);
  padding: var(--spacing-md);
}

Q202 — What is CSS calc() and when would you use it? Easy → Medium

✅ Ideal answer calc() allows us to perform calculations between CSS values. It's useful when combining different units (e.g., width: calc(100% - 40px);).
🔁 Follow-up: Can you use CSS variables inside calc()? Yes: height: calc(100vh - var(--header-height));

💻 Code

style.css — Visual Studio Code
style.css
.container {
  width: calc(100% - 40px);
}

.dashboard {
  height: calc(100vh - 64px); /* Fixed header */
}

Q203 — What is the difference between min(), max(), and clamp()? Hard

✅ Ideal answer
  • min() chooses the smallest value.
  • max() chooses the largest value.
  • clamp(min, preferred, max) limits a value between a minimum and maximum.
clamp() is useful for fluid responsive sizing without needing many media queries.
🔁 Follow-up: Why is clamp() useful? It allows fluid responsive sizing (e.g., font-size) to scale with the viewport but not go below a minimum or above a maximum.

💻 Code

style.css — Visual Studio Code
style.css
.title {
  font-size: clamp(1rem, 2vw, 2rem);
}

Q204 — What is a CSS Cascade Layer (@layer)? Hard

✅ Ideal answer @layer allows us to explicitly organize CSS into cascade layers and control their precedence.

This can make large stylesheets easier to reason about and reduce the need for specificity hacks.
🔁 Follow-up: Why can cascade layers be useful with third-party libraries? They can help establish a predictable cascade relationship between library styles, application styles, components, and utilities.

💻 Code

style.css — Visual Studio Code
style.css
@layer reset, components, utilities;

@layer reset {
  .button { background: gray; }
}
@layer components {
  .button { background: blue; }
}
@layer utilities {
  .button { background: green; } /* Wins */
}

🔴 Live demo

Layers are declared as: reset, components, utilities. The button ends up green because `utilities` was declared last.

Q205 — What is !important, and why should it generally be avoided? Medium

✅ Ideal answer !important increases the priority of a declaration in the cascade. It can be useful in specific cases, but excessive use creates specificity and maintenance problems.
🔁 Follow-up: Is !important always bad? No. There are legitimate use cases, but it should be deliberate rather than the default solution.

💻 Code

style.css — Visual Studio Code
style.css
.button {
  background: blue;
}
.button {
  background: red !important; /* This wins */
}

🔴 Live demo

Q206 — What is the difference between CSS transitions and animations? Easy → Medium

✅ Ideal answer A transition describes how a property changes between states (e.g., on hover).

An animation can define multiple keyframes and doesn't necessarily depend on a state change (it can run automatically).
🔁 Follow-up: Can a transition run automatically when the page loads? A transition normally needs a change between states/values. If I need a standalone sequence, CSS animation is usually more appropriate.

💻 Code

style.css — Visual Studio Code
style.css
/* Transition (on hover) */
.button { transition: transform 0.2s; }
.button:hover { transform: scale(1.1); }

/* Animation (auto-run) */
@keyframes spin { to { transform: rotate(360deg); } }
.loader { animation: spin 1s infinite; }

Q207 — What are CSS animation keyframes? Easy

✅ Ideal answer Keyframes define the intermediate states of a CSS animation (using from/to or percentages like 0%, 50%, 100%).
🔁 Follow-up: What's the difference between animation-duration and animation-delay? duration is how long the animation takes, while delay is how long the browser waits before starting it.

💻 Code

style.css — Visual Studio Code
style.css
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

.element {
  animation: fadeIn 500ms ease;
}

Q208 — What is the difference between em, rem, %, vw, vh, and px? Medium

✅ Ideal answer
  • px: Absolute CSS pixel unit.
  • rem: Relative to the root font size.
  • em: Relative to the element's/parent's font size (can compound).
  • %: Relative to a containing dimension.
  • vw / vh: 1% of the viewport width/height.
🔁 Follow-up: Why do many developers prefer rem for typography? Because it's relative to the root font size, making typography more predictable and easier to scale consistently.

💻 Code

style.css — Visual Studio Code
style.css
html { font-size: 16px; }
.rem-box { font-size: 1.5rem; } /* 24px */
.em-box { font-size: 1.5em; }   /* 1.5x parent */
.vw-box { font-size: 3vw; }
.hero { min-height: 100vh; }

Q209 — How do media queries work, and what is mobile-first CSS? Medium

✅ Ideal answer Media queries apply CSS conditionally based on characteristics such as viewport width.

A mobile-first approach means starting with the base styles for smaller screens and progressively enhancing them for larger screens.
🔁 Follow-up: Why is mobile-first often preferred? It encourages simpler base styles and progressive enhancement. It can also make responsive rules easier to maintain.

💻 Code

style.css — Visual Studio Code
style.css
/* Mobile First */
.container { display: block; }

@media (min-width: 768px) {
  .container { display: grid; }
}

Q210 — How would you debug a CSS layout bug where an element is not appearing where you expect? Hard

✅ Ideal answer I wouldn't randomly add CSS properties. I'd debug systematically using DevTools:
  1. Check computed styles, box model, and dimensions.
  2. Check if it's hidden (display: none, visibility: hidden, opacity: 0).
  3. Check layout context (Flex, Grid, Absolute).
  4. Check positioning and containing blocks.
  5. Check cascade (specificity, !important).
  6. Check overflow (clipped by an ancestor).
🔁 Follow-up: What if the element exists in the DOM but you can't see it? It could be hidden, have zero dimensions, be outside the visible area, be clipped by overflow, have a stacking issue, or be visually transparent.

💻 Code

style.css — Visual Studio Code
style.css
.container {
  height: 80px;
  overflow: hidden; /* The bug */
}

.container.fixed {
  overflow: visible;
  height: auto;
}

🔴 Live demo

This box is pushed down. Without the fix, it gets clipped by `overflow: hidden`.
